## Source tree (planned shape — see SPEC §6)

Will populate in task #5 (skeleton). Sketch from API design + SPEC §6:

```
src/
  core/                  Pure Zig, no I/O
    decoder.zig          Public Decoder primitive (open, ifd, decodeStrip)
    source.zig           Source vtable + fromBuffer/fromMmap/fromFile/fromBufferedReader
    workspace.zig        Per-call codec scratch holder
    limits.zig           Limits struct + defense-in-depth checks
    errors.zig           Single canonical error set (build.zig reads this for C header gen)
    ifd.zig              IFD parsing (tag dictionary, lazy values)
    bigtiff.zig          Comptime offset-width abstraction (u32 / u64)
    compressions/
      uncompressed.zig
      packbits.zig
      lzw.zig
      deflate.zig
      ccitt_t4.zig
      ccitt_t6.zig
      jpeg.zig           (M9.5 — wraps sibling jpegz)
    predictors.zig       None / Horizontal / Floating-point
    photometrics.zig     RGB / palette / CMYK / YCbCr / Lab
    convenience.zig      validateAll / decodeStreaming / decodeAll
ffi/
  c_api.zig              Exported C ABI; toCStatus mapper
  tiffz_core.h           Generated by build.zig from src/core/errors.zig
include/
  tiffz_errno.h          Generated by build.zig (stable enum, append-only)
cli/
  main.c                 Dogfoods the C FFI for I/O
tests/
  unit/                  Zig unit tests (build.zig integration)
  cli/                   Bash-driven CLI surface tests
  fixtures/              Generated + acquired TIFFs (per SPEC Appendix B)
  abi/error_codes.snapshot.txt   CI guard against accidental enum reordering
audit/
  coverage_matrix.tsv    Empirical zigimg-vs-tiffz variant matrix (task #4)
build.zig
build.zig.zon
```
