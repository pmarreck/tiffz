# License audit of committed fixtures

validate requested this on 2026-11-05 for BDFN. It covers every file under
`tests/fixtures/`: 131 files, audited 2026-11-07. Nothing was deleted and no
history was rewritten. What to do with the files of unknown license is BDFN's
decision.

## Method

- Size, SHA-256 and the commit that added each file come from the tree and
  from `git log --diff-filter=A`.
- Where a public source exists, origin was checked byte for byte against:
  - libtiff 4.7.2's `test/images`, from the nixpkgs libtiff source;
  - libtiff's pics archive, pics-3.8.0.tar.gz from download.osgeo.org;
  - raw.pixls.us.
- Otherwise the evidence is, in order of preference:
  - a generator script in the repo;
  - commit messages and test comments;
  - tags embedded in the file.
- An oracle `.rgba` file is a decode of the fixture of the same name, so its
  license follows that fixture's.
- The table is generated from the tree. Its classification rules are
  explicit, and every file must match one of them.

The unknown-license files total 21: 13 images and 8 oracle decodes of them.

Readings:

- **libtiff pics 3.8.0.** The archive states no license. Its README asked
  contributors for images "that do NOT HAVE A COPYRIGHT," but it also credits
  some images to others, such as "bowling pins" from Pixar for strike.tif.
  The archive has circulated with libtiff for decades. That is not a license.
- **libtiff test/images.** These ship inside the libtiff source tarball,
  under its LICENSE.md. Their README says deflate-last-strip-extra-data.tiff
  is GDAL autotest's utmsmall_near.tiff. That provenance is recorded, not
  verified.
- **bali.tif.** tlnagy/exampletiffs lists its license as "?" and credits
  John Burkardt's TIFF data page. Its Software tag reads ImageMagick 6.3.3.
- **The CR2.** Byte-identical (sha1 5d07ebfa) to raw.pixls.us Canon EOS 40D
  `_MG_0154.CR2`. Uploaders to raw.pixls.us release their files under CC0.
- **Tool-generated fixtures.** The tools, ImageMagick, tiffcp, gdal_translate
  and libtiff, add no license of their own to synthetic output. These files
  are this repo's own work, but their generation is not reproducible from the
  repo the way the script-generated files are.
